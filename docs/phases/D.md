- 13:50 — Reconsolidation returns **patch ops** (merge/abandon/complete/relink) rather than a free rewrite of activeTasks/recentCompleted; its `flag_opportunity` ops are stripped (only Tier 2 may flag).
- 13:52 — Deterministic gate before the Judge (`core/suggest.gateJudge`): task boundary (a `completed` event in this batch) + Tier-2 flag + ≥2 completed instances OR ≥3 lineage edges in the task + not dismissed + per-pattern cooldown 30 min. The LLM can only make suggestions rarer.
- 13:55 — Suggestion state is owned by extension `modules/observe` (`suggestions.ts`, `storage.local wwa_suggestions`), generation by `modules/jobs` (`jobs.start/cancel/get` services). Accept adopts the job's widget through a new `widgets.adopt` service → **unapproved** `WidgetRecord` → `WIDGET_GENERATED` → approval card in the Create tab (panel jumps there via `SuggestionRouter`); `chrome.sidePanel.open` is attempted on the card click (user gesture). Never auto-runs.
- 13:55 — "Not now" = hide (snoozed, job result kept, listed in Activity). "Never for this" = status dismissed + cancel live job + `POST /api/observe/dismiss` (WorkingMemory.dismissed, shown to the Judge). Restore (Activity tab) = `POST /api/observe/restore` (also clears the pattern's cooldown) and re-lists the suggestion (ready if the job result exists, else a new job) without re-showing the card.
- 13:55 — Clear observation keeps dismissals (negative feedback should survive a clear).
- 13:58 — Job cancel cannot abort the in-flight LLM call (`callModel` has no AbortSignal): the job flips to `cancelled` at once and the late result is discarded by the pure state machine (terminal states absorbing). Jobs left `queued/running` at backend start are marked failed. Jobs are per user (`x-user-id`), dedupe by `dedupeKey = patternId:specHash` (§7 "one live job per pattern").
